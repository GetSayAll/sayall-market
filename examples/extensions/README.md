# External Extension Listings（Draft）

这里保存可以公开展示的外部扩展介绍 Draft，例如外壳、配件或外部项目链接。

## 文件

- `makerworld-accessories.json` 是结构化事实源，官网开放市场构建时读取此文件。
- `makerworld-accessories.draft.md` 是公开预览，由 JSON 生成。修改 JSON 后运行 `npm run sync:market`；`npm run validate` 会拒绝两者不一致的状态。

这些文件是公开内容候选，不是客户端可安装包，也不是生产目录。当前仓库处于 `Public Design Preview / Contributions Paused`：

- 不代表无线麦 SayAll App 已经兼容或验证相关内容；
- 不代表 GetSayAll 制造、销售、授权、担保或售后；
- 不包含内部规划、商业化判断、审核资料或用户本地数据；
- 正式目录和客户端消费合同仍以获得批准的 Schema 与发布流程为准。
