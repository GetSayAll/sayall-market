# 无线麦SayAll.app 常用语

这是无线麦SayAll.app 内置常用语的公开候选目录。

- 官网：<https://sayall.app>
- GitHub：<https://github.com/sayall-market/common-phrases>
- 内容源：`built-in.md`
- 导入文件：`common-phrases.json`

`common-phrases.json` 保留 App 导入导出使用的 `website` 和 `github` 来源字段。当前目录属于 SayAll Market 的候选内容，正式发布前仍需完成维护者审核和真实目标输入框验证。
