# 仓库范围

## 本仓库保存

- 公开 Schema 和版本历史；
- 系统、官方和社区宏；
- 遥控器布局模板；
- 公开目录索引；
- 贡献、安全和内容验证规范。

这是客户端和社区可以审阅、验证及消费的共享内容来源。

## 本仓库不保存

- 市场服务、作者身份服务或运营后台实现；
- 内部审核资料、签名密钥和安全响应细节；
- 无线麦客户端业务代码、蓝牙或 HID 实现；
- 用户本地覆盖、设备绑定和输入框学习数据；
- 内部研究、商业判断或未公开路线图。

## 数据边界

- 已发布 Schema、宏和布局保留公开版本历史；
- 用户本地覆盖、设备绑定和输入框学习只保存在用户设备；
- 正式内容通过公开 Pull Request 和维护者审核进入；
- 同一发布版本不得在公开历史之外被静默替换。
