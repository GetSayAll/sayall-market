A

结论

WPS Office for Mac 支持用键盘启动和控制 PPT 放映。 WPS 官方 Mac 快捷键页列出 F5、Shift+F5、方向键、Esc、⌘B 和窗口切换键。 这些快捷键可以表达遥控器的主要 macOS 放映操作。

当前仓库新增 macOS 平台维度。 WPS 方案放在 examples/profiles/。 macOS 使用 .sayall 文件。 该方案尚未完成验收，也不进入下载包。

B

平台维度

布局模板必须声明 platforms。 本轮布局使用 ["macOS"]。 客户端不得从 App 名称推断平台。 本轮只处理 macOS。 Windows 方案暂不作为本轮验证目标。

正式 sayall-transfer 1.0 仍保持兼容。 现有正式包主要面向 macOS。 未来正式合同需要单独定义平台字段和 Windows 读取行为。

WPS 官方页面说明，部分 macOS 系统的快捷键可能与其他 App 冲突。 因此，表格中的 ok 只表示公开资料有记录，不表示本机验收完成。 ⌘B 在编辑状态也可能表示粗体。 客户端必须只在放映状态发送这个映射。

验证步骤

  1. 在 macOS 打开 WPS 演示文稿。
  2. 记录 WPS 版本、macOS 版本和显示器数量。
  3. 在编辑状态测试 F5 和 ⇧F5。
  4. 在放映状态测试 Space、方向键、Esc 和 ⌘B。
  5. 打开两个 PPT，测试 ⌃Tab 和 ⇧⌃Tab。
  6. 使用真实遥控器逐键测试单击和双击。
  7. 记录失败按键、焦点状态和回退动作。

自动化检查不能替代真实遥控器验收。
