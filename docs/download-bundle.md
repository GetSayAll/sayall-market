## B 解压与导入

1. 下载 ZIP，并在 Mac 上解压。
2. 打开无线麦SayAll.app 的「键位方案」。
3. 选择「导入」，再选择需要的 `.sayall` 文件。
4. 检查方案名称、遥控器型号和全部按键。
5. 确认后保存，再选择或启用该方案。
6. 如需其他方案，重复导入对应文件。

Mac App 导入方案文件，不直接导入 ZIP。
若只需要一套方案，可使用表中的单套下载入口。
需要使用已提供键位方案导入功能的客户端。

## C 使用前检查

这些文件是 1.0 方案。部分 App 与实体遥控器仍需验收。
先检查按键效果，再用于日常操作。
下载集合不会改变各方案的验证状态。

全键盘控制方案需要启用 Mac 的「全键盘控制」。
在「系统设置 → 辅助功能 → 键盘」中开启该功能。
方案不会自动更改系统设置。

网易云的上键和主页键均设为喜欢歌曲。
网易云的播放和切歌作用于系统当前媒体会话。
这些按键可能控制其他播放器。
剪映的音量+暂不设置，待确认默认放大键值。
